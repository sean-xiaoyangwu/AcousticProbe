# AcousticProbe — 工作记录 2026-04-25

## 项目背景

AcousticProbe 是 MIT 6.808 课程项目（Xiaoyang Wu, Hang Zhao, Chloe Ni）。
目标：用 iPhone 内置扬声器/麦克风发射 18–22 kHz FMCW 超声信号，通过被动声学附件增强特定方向的人体活动检测（HAR）能力。

## 一、管状导波结构设计参数

### 本次推进方向

放弃 proposal 中三个 prototype（spiral waveguide / Helmholtz / quarter-wave resonator），
改为设计一个 **3D 打印管状结构**，通过几何遮蔽提升 FMCW 检测的方向性。

### 核心公式

几何接受角（半角）：

```
θ = arctan(D / 2L)
```

变形：
- 已知 D 和目标角 → 管长：`L = D / (2·tan(θ))`
- 已知 L 和目标角 → 内径：`D = 2L·tan(θ))`

| 内径 D | 管长 L | 几何接受角 θ |
|--------|--------|-------------|
| 15 mm  | 30 mm  | ±14°        |
| 20 mm  | 30 mm  | ±18°        |
| 15 mm  | 50 mm  | ±8.5°       |
| 20 mm  | 50 mm  | ±11°        |

### 推荐参数

- **内径：15–20 mm**（~1–1.5λ，λ = 17.2 mm @20 kHz）
- **管长：3–5 cm**（对应 ±8–14° 接受角，适合 iPhone 附件）
- 内壁光滑硬质（PVC / ABS），减少杂散反射
- 管长引入固定 range offset = 管长（可在分析时校准）

### 频率参考

| 频率 | 波长 λ |
|------|--------|
| 18 kHz | 19.1 mm |
| 20 kHz | 17.2 mm |
| 22 kHz | 15.6 mm |

单模传播上限（仅平面波）：D < 9.1 mm（实用中可放宽，接受多模）

## 二、三组录音实验分析

三组录音使用不同长度的管状结构，其余条件相同。

| 录音文件 | 管长 | Range profile 峰值 | 相对 SNR |
|---------|------|--------------------|----------|
| fmcw_1776965377.wav | 短管 | 0.0015 | 1× |
| fmcw_1776965441.wav | 中管 | 0.003  | 2× |
| fmcw_1776965604.wav | 长管 | 0.025  | **17×** |

### 修复前分析（原始结果）

**…377（短管）：**
- Range profile 全为均匀红色噪声，peak tracker 在 0–2.5 m 随机跳
- Phase displacement 出现 80 mm 单调漂移（0–6 s），系统未锁定稳定目标

**…441（中管）：**
- Range profile 在 t≈10, 13, 21, 27, 31 s 有明显亮竖条（物理扰动事件）
- SNR 约为短管 2×，安静段可见目标锁定在 0.5–1.0 m
- Phase 有漂移但趋势中可见慢波分量

**…604（长管）：**
- Range profile 背景接近全黑，信号高度集中，峰值为短管 **17×**
- 距离追踪稳定，节律性振荡可见
- Phase 振荡结构最清晰，为唯一可直接用于呼吸率估计的录音

### 漂移问题根因

`analyze_fmcw.py` 使用固定 `median_bin` 提取相位，目标稍微移动即导致累积相位漂移，
表现为 phase displacement 出现几十 mm 量级的 DC 漂移而非以 0 为中心的振荡。

## 三、算法修复

### 修改文件：`analyze_fmcw.py`

**新增两个零相位滤波函数：**

```python
def highpass_zp(data, cutoff, fs, order=2):
    sos = signal.butter(order, cutoff, btype='high', fs=fs, output='sos')
    return signal.sosfiltfilt(sos, data)      # 双向，零相位

def bandpass_zp(data, low, high, fs, order=2):
    sos = signal.butter(order, [low, high], btype='band', fs=fs, output='sos')
    return signal.sosfiltfilt(sos, data)
```

**相位提取段修改：**

```python
# 修复前
displacement_mm = ...
resp_signal = lowpass(displacement_mm, 3.0, 1/T, order=3)

# 修复后
displacement_mm = ...
displacement_detrended = signal.detrend(displacement_mm)         # 去线性趋势
displacement_detrended = highpass_zp(displacement_detrended, 0.05, 1/T)  # 去慢漂 (<0.05 Hz)
resp_signal = bandpass_zp(displacement_detrended, 0.1, 3.0, 1/T)         # 呼吸带通
```

修复逻辑：
1. `signal.detrend` 去除线性趋势分量
2. 高通 0.05 Hz 去除残余慢速非线性漂移
3. 带通 0.1–3 Hz 替换原来的低通 3 Hz，下边界截掉漂移，保留呼吸频段（0.1–1 Hz）
4. 使用 `sosfiltfilt`（零相位）替换 `sosfilt`，避免相位失真，保留呼吸波形形状

### 新增文件：`run_analysis.py`

基于 tkinter 的 GUI 启动器：运行后弹出文件选择窗口，选择 WAV 文件即可自动完成分析并弹出 PNG 结果。

```bash
python run_analysis.py
```

## 四、修复后结果分析

**…377（短管）：**
- Phase 漂移消除，以 0 为中心，幅度 ±20 mm
- 红色呼吸线可见周期约 3–4 s（15–20 次/分），但蓝线毛刺多，SNR 不足，可信度低

**…441（中管）：**
- Phase 周期更清晰，但 t=10–14 s 扰动事件导致大幅跳变，污染该段相位
- 安静段（0–9 s、15–25 s）可见较干净慢波

**…604（长管）：**
- 约 t=2, 6, 10, 15, 20, 25 s 各一个峰，25 s 内 5–6 个完整周期
- 估计呼吸率：**~12–14 次/分**（正常静息值）
- 蓝线与红线几乎重合，高频噪声本身极少

### 最终对比

| | …377（短） | …441（中） | …604（长） |
|---|---|---|---|
| 漂移修复 | ✓ | ✓ | ✓ |
| 呼吸波形可辨 | 勉强 | 有扰动 | **清晰** |
| 估计呼吸率 | 不可靠 | 部分可用 | ~13 次/分 |
| 限制因素 | SNR 不足 | 运动干扰 | 无明显问题 |

**结论：** 管越长 SNR 越高（17× 差距），方向性增强效果显著，支持 proposal 的 H1 假设。
Recording 604 的呼吸波形可直接用作 demo 图和 benchmarking 数据。
