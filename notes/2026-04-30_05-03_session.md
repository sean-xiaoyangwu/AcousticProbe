## 一、文献调研：手机 FMCW 前人工作

### 关键发现：真实分辨率 vs 零填充

**当前代码报告的 10.7 mm/bin 是零填充插值，不是真实分辨率。**

真实 range resolution：
```
Δr = c / (2B) = 343 / (2 × 4000) = 42.9 mm ≈ 4.3 cm
```

NFFT = N×4 的零填充只让 FFT 曲线更平滑，不创造新信息。这是追踪抖动的根本原因之一。

### 调研的主要项目

| 项目 | 精度 | 关键技术 | 结论 |
|------|------|---------|------|
| **FingerIO** (UW, 2016) | 8 mm | OFDM 调制 + 相位提取 | 参考思路，不可直接用 |
| **KevinsWang/fmcw-acoustic-gesture** | 未报告 | MATLAB, 17–23 kHz, Hanning 窗 | 参考思路，借鉴参数 |
| **LibAcousticSensing** (UW) | N/A | Obj-C iOS + MATLAB 服务器 | Standalone 未完成，不可用 |

**两个 repo 共同问题：** 纯 MATLAB/服务器架构，无片上 DSP，2018 年废弃，无分类器。

### 借鉴到的具体改进

1. **Hanning 窗**（来自 KevinsWang）：17–23 kHz 的宽带设计 + Hanning 窗 + 高通 16 kHz 滤波
2. **Cross-correlation chirp 对齐**（来自 KevinsWang pipeline）
3. **带宽建议**：KevinsWang 用 17–23 kHz（B=6 kHz）比我们的 18–22 kHz（B=4 kHz）分辨率好 1.5×，是 iOS app 的 future work

## 二、Phase Integration 追踪实验

### 实现

在 Plot 3 上叠加第三条线（红色）：相位积分位移锚定到 target_m：

```python
disp_m_raw      = (phase_unwrapped - phase_unwrapped[0]) * c / (4 * np.pi * fc)
phase_tracked_m = target_m + disp_m_raw
```

### 结论

| 手势类型 | Argmax 追踪 | Phase Integration |
|---------|-----------|------------------|
| 大位移（前倾 50cm, 伸手 30cm） | ✅ 清晰台阶/尖峰 | ❌ 单调漂移，相位展开失败 |
| 小位移（呼吸 <1cm） | ❌ 低于分辨率 | ✅ mm 级连续追踪 |

**原因：** 50cm 位移需展开 ≈63 圈（λ/2=8.6mm），手机音频相位噪声导致累积展开误差。

**结论：两通道设计（argmax 做手势 + phase 做呼吸）已是最优分工。**

## 三、信号处理改进（借鉴 KevinsWang）

### 3.1 Hanning 窗

```python
hann_win     = np.hanning(N)
complex_ffts = np.fft.rfft(mixed_lp * hann_win, n=NFFT, axis=1)
```

效果：矩形窗旁瓣 -13 dB → Hanning 窗 -31 dB，近场泄漏对相邻 bin 的污染减少，噪底降低约 33%。

### 3.2 Cross-correlation Chirp 对齐

```python
corr   = np.abs(np.correlate(rx_filtered[:search_len], tx_chirp, mode='valid'))
offset = int(np.argmax(corr))
rx_aligned = rx_filtered[offset:]
```

效果：修正音频 buffer 时序抖动。测试录音检测到 1915 samples 的起始偏移。

## 五、Gesture Metrics 讨论

对比不同结构时的严格指标体系：

| 优先级 | Metric | 说明 |
|--------|--------|------|
| ★★★ | **AUC of ROC curve** | 扫描阈值，画 Detection Rate vs False Alarm Rate 曲线 |
| ★★★ | **Signal-to-Clutter Ratio (SCR)** | 手势期峰值 / 静止期平均，不需要分类器 |
| ★★☆ | Detection Rate @ fixed FAR | 公平比较各结构的检测率 |
| ★☆☆ | Per-gesture F1 | 需要分类器 + 详细标注 |

**前提：** 需要控制变量实验（固定人、距离、手势类型，只换结构），并手动标注手势时间戳。
